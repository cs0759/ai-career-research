### What a student can learn

The titles sound specialized, but employers repeatedly value **Python/JavaScript, APIs, databases, debugging, shipping a working application, and explaining design decisions**. Google lists relatively advanced AI production requirements even for interns; Coinbase explicitly recognizes hackathons and class projects. These are different entry barriers.

## Student-oriented comparison

| Question | Forward Deployed Engineer | AI / Agent Engineer |
| --- | --- | --- |
| Typical daily focus | Integrate and deploy software with stakeholders | Build, test and operate AI-backed applications |
| Transferable web skills | APIs, databases, full-stack coding, documentation | Backend APIs, frontend integration, tests, data |
| New skills to build | Cloud deployment, RAG, evaluation, customer discovery | Tool calling, orchestration, evaluation, observability |
| Strong portfolio evidence | Deployed app integrated with external systems | Working agent with failure handling and tests |

## Suggested starter portfolio project

Build a **career-research assistant** with a web frontend, a Python or Node backend, a database of sourced job postings, and retrieval that always links answers to employer postings. Add tests for incorrect answers and a clear note about when jobs were last checked. This demonstrates full-stack, AI integration, data quality and evaluation skills.
