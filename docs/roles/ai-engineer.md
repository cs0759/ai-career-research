# AI Engineer

## What does this role do?

AI engineers build software systems that use machine learning or foundation models to solve practical problems. The title varies: some positions emphasize model development while others focus on integrating existing models.

## Common responsibilities

- Develop AI-backed features and services.
- Connect applications to model APIs and data sources.
- Evaluate accuracy, latency, reliability, and cost.
- Deploy, monitor, and improve AI systems.

## Skills to investigate

Python, software engineering, APIs, data pipelines, model evaluation, cloud services, and ML fundamentals.

## Research questions

Does the employer expect model training, application engineering, or both? What production experience is required?
