# Emerging AI Career Paths

AI job titles are evolving quickly. The descriptions below summarize common responsibilities, not universal definitions.

| Role | Typical focus |
| --- | --- |
| [Forward Deployed Engineer](/roles/forward-deployed-engineer) | Deliver AI/software solutions in a customer's real environment |
| [AI Engineer](/roles/ai-engineer) | Build and integrate AI-powered applications |
| [LLM Engineer](/roles/llm-engineer) | Develop and evaluate language-model systems |
| [AI Agent Engineer](/roles/ai-agent-engineer) | Build tool-using and multi-step AI workflows |
| [AI Solutions Architect](/roles/ai-solutions-architect) | Design AI systems that fit organizational needs |

## Comparing roles

Titles overlap significantly. Compare job descriptions by the actual work: application development, model training, evaluation, infrastructure, customer delivery, or architecture.
