# AI Agent Engineer

## What does this role do?

AI agent engineers create systems where models can select tools, use external services, and execute multi-step tasks under defined controls.

## Common responsibilities

- Implement tool calling and workflow orchestration.
- Manage state, retries, and failure handling.
- Evaluate task completion, reliability, and security.
- Integrate agents with applications and enterprise systems.

## Skills to investigate

Python or TypeScript, API design, orchestration, testing, observability, permissions, and evaluation.

## Research questions

When is a deterministic workflow preferable to an autonomous agent? How do employers measure reliability?
