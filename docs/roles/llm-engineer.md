# LLM Engineer

## What does this role do?

An LLM engineer designs applications and infrastructure around large language models. Work can include retrieval-augmented generation (RAG), prompting, fine-tuning, evaluation, and inference optimization.

## Common responsibilities

- Build LLM-powered applications and pipelines.
- Design retrieval and grounding systems.
- Test output quality, safety, and reliability.
- Improve response latency and operational cost.

## Skills to investigate

Python, transformers, embeddings, vector search, RAG, evaluation frameworks, and model serving.

Is the job focused on fine-tuning and inference, or on product integration? Which evaluation methods are required?
