# Forward Deployed Engineer (FDE)

## What does this role do?

A forward deployed engineer works closely with customers or internal stakeholders to implement and adapt software in real operating environments. In AI companies, the work may include integrating models into existing workflows, handling data connections, building prototypes, and shipping production-ready features.

## Common responsibilities

- Translate user and business problems into technical requirements.
- Build integrations, APIs, and application features.
- Debug deployment and data issues in customer environments.
- Collaborate directly with product, engineering, and customer teams.

## Skills to investigate

Python, TypeScript, APIs, SQL, cloud deployment, debugging, communication, and applied AI evaluation.

## Questions for research

How much time is spent coding versus working with customers? How does the role differ from solutions engineering and implementation engineering?
