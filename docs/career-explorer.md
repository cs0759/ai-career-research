## Suggested student pathway

1. **Foundation:** GitHub, HTML/CSS, JavaScript, Node.js, Python, SQL and HTTP APIs.
2. **Ship a project:** Build a web app with authentication, database and deployed backend.
3. **Add AI responsibly:** Integrate an API, document limitations and test results.
4. **Make it production-minded:** Logging, error handling, basic security and evaluations.
5. **Apply:** Prioritize internships and genuinely junior roles, checking location and eligibility.
6. **Grow:** Build experience before targeting staff-level architecture or specialized FDE roles.
