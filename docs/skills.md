# Skills Roadmap

These are suggested learning areas to investigate, not verified requirements for every role.

## Foundation

1. **Programming:** Python and JavaScript/TypeScript.
2. **Web and backend:** HTTP, REST APIs, authentication, databases, and Git.
3. **Data:** SQL, data cleaning, embeddings, and retrieval.
4. **AI fundamentals:** Model capabilities, limitations, evaluation, and responsible deployment.
5. **Production engineering:** Testing, logging, monitoring, cloud deployment, and security.

## Portfolio project ideas

- Build an AI research assistant that cites retrieved documents and evaluates answer quality.
- Create a tool-using agent with permissions, audit logs, and failure recovery.
- Deliver a small end-to-end AI integration for a realistic stakeholder workflow.

## Role-specific emphasis

| Role | Strong starting emphasis |
| --- | --- |
| Forward Deployed Engineer | Full-stack engineering, integrations, customer discovery |
| AI Engineer | Application development, ML basics, deployment |
| LLM Engineer | RAG, model evaluation, inference |
| AI Agent Engineer | Tool calling, orchestration, testing |
| AI Solutions Architect | System design, security, cloud platforms |
