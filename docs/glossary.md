# Beginner Glossary

**API (Application Programming Interface):** A defined way for software systems to exchange requests and responses.

**RAG (Retrieval-Augmented Generation):** Finding relevant documents or data and giving that context to a language model before it responds.

**MCP (Model Context Protocol):** A protocol used to connect AI applications to tools and data sources.

**LLMOps:** Engineering practices for deploying, evaluating, monitoring and maintaining language-model systems.

**Agent:** A system that uses a model to choose or coordinate steps, potentially calling tools and services.

**Evaluation (evals):** Structured tests of model or application behavior, including correctness, reliability and safety.

**Observability:** Logs, metrics and traces that help engineers understand how a system behaves.

**Forward deployed:** Working closely with customers or stakeholders to implement software in their actual environment.

**Hybrid:** Some work is in person; it does not mean fully remote.

**US remote:** Remote work within the United States, possibly restricted to certain states.
